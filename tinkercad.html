Desafio 1 — Iluminação Inteligente

Sistema que liga uma lâmpada (LED) automaticamente apenas quando há duas condições verdadeiras ao mesmo tempo: presença de uma pessoa no ambiente (detectada pelo sensor PIR) e baixa luminosidade (detectada pelo LDR). É a lógica clássica por trás da iluminação automática de corredores e áreas comuns, que evita desperdício de energia ao não acender luzes em ambientes já iluminados naturalmente.

Circuito

Código em C++

const int pinPIR = 2; const int pinLDR = A0; const int pinLED = 13; const int limiteLuz = 500; // Ajuste conforme o nível de escuro desejado void setup() { pinMode(pinPIR, INPUT); pinMode(pinLED, OUTPUT); } void loop() { int presenca = digitalRead(pinPIR); int valorLuminosidade = analogRead(pinLDR); // Regra: Pessoa presente + ambiente escuro -> LED ligado if (presenca == HIGH && valorLuminosidade < limiteLuz) { digitalWrite(pinLED, HIGH); } else { digitalWrite(pinLED, LOW); } delay(100); }

Desafio 2 — Estacionamento Inteligente

Sistema de auxílio ao estacionamento que mede continuamente a distância até um obstáculo com um sensor ultrassônico (HC-SR04) e sinaliza o quão perto o veículo está através de um LED. Um potenciômetro permite ajustar o limite de segurança entre 10 cm e 60 cm, simulando um controle de sensibilidade. Quando o objeto está distante, o LED permanece apagado; ao se aproximar, o LED começa a piscar cada vez mais rápido; e, muito próximo, fica aceso de forma contínua — o mesmo comportamento dos sensores de ré encontrados em veículos reais.

Circuito

Código em C++

const int pinTrig = 9; const int pinEcho = 8; const int pinPot = A0; const int pinLED = 3; long lerDistancia() { digitalWrite(pinTrig, LOW); delayMicroseconds(2); digitalWrite(pinTrig, HIGH); delayMicroseconds(10); digitalWrite(pinTrig, LOW); long duracao = pulseIn(pinEcho, HIGH); return duracao * 0.034 / 2; // Converte tempo em centímetros } void setup() { pinMode(pinTrig, OUTPUT); pinMode(pinEcho, INPUT); pinMode(pinLED, OUTPUT); } void loop() { long distancia = lerDistancia(); int valPot = analogRead(pinPot); // O potenciômetro define o limite de segurança entre 10cm e 60cm int limite = map(valPot, 0, 1023, 10, 60); int limitePerigo = limite / 2; if (distancia > limite) { digitalWrite(pinLED, LOW); // Objeto distante } else if (distancia <= limitePerigo) { digitalWrite(pinLED, HIGH); // Objeto muito próximo (ligado contínuo) } else { // Objeto se aproximando: velocidade do pisca aumenta conforme chega perto int tempoPisca = map(distancia, limitePerigo, limite, 40, 300); digitalWrite(pinLED, HIGH); delay(tempoPisca); digitalWrite(pinLED, LOW); delay(tempoPisca); } delay(30); }

Desafio 3 — Ambiente Inteligente

Estação de monitoramento ambiental que lê temperatura (sensor TMP36) e umidade (simulada por um potenciômetro), acendendo LEDs indicadores conforme a condição do ambiente: verde para condições adequadas, vermelho para temperatura elevada e amarelo para umidade baixa. Todas as leituras também são enviadas ao Monitor Serial em tempo real, exibindo o status textual da leitura — recurso muito usado em sistemas reais de monitoramento remoto antes do envio dos dados para a nuvem.

Circuito

Monitor Serial

Código em C++

const int pinTemp = A0; const int pinUmidade = A1; const int ledVerde = 2; const int ledVermelho = 3; const int ledAmarelo = 4; const float tempLimite = 30.0; // Limite superior de temperatura (°C) const int umidadeLimite = 40; // Limite inferior de umidade (%) void setup() { pinMode(ledVerde, OUTPUT); pinMode(ledVermelho, OUTPUT); pinMode(ledAmarelo, OUTPUT); Serial.begin(9600); // Inicializa comunicação serial exigida } void loop() { // Conversão de leitura analógica do TMP36 para Celsius int leituraTemp = analogRead(pinTemp); float voltagem = leituraTemp * (5.0 / 1023.0); float temperatura = (voltagem - 0.5) * 100.0; // Conversão da leitura do potenciômetro para porcentagem de umidade int umidade = map(analogRead(pinUmidade), 0, 1023, 0, 100); bool tempElevada = (temperatura > tempLimite); bool umidadeBaixa = (umidade < umidadeLimite); // Lógica dos LEDs indicadores if (!tempElevada && !umidadeBaixa) { digitalWrite(ledVerde, HIGH); digitalWrite(ledVermelho, LOW); digitalWrite(ledAmarelo, LOW); } else { digitalWrite(ledVerde, LOW); digitalWrite(ledVermelho, tempElevada ? HIGH : LOW); digitalWrite(ledAmarelo, umidadeBaixa ? HIGH : LOW); } // Saída de dados no Monitor Serial Serial.print("Temperatura: "); Serial.print(temperatura); Serial.print(" C | Umidade: "); Serial.print(umidade); Serial.print("% | Status: "); if (tempElevada && umidadeBaixa) { Serial.println("ALERTA CRÍTICO (Temp Alta + Umidade Baixa)"); } else if (tempElevada) { Serial.println("Alerta: Temperatura Elevada"); } else if (umidadeBaixa) { Serial.println("Alerta: Umidade Inadequada"); } else { Serial.println("Condicoes Adequadas"); } delay(1000); }
