ESP8266 / NodeMCU

Conceito, características técnicas e circuitos práticos com o microcontrolador Wi-Fi mais popular do mercado maker

O que é o ESP8266?


O ESP8266 é um microcontrolador com Wi-Fi integrado, desenvolvido pela empresa chinesa Espressif Systems e lançado em 2014. Diferente do Arduino Uno tradicional, que precisa de um módulo ou shield externo para se conectar à internet, o ESP8266 já nasce com um rádio Wi-Fi 802.11 b/g/n embutido no próprio chip, o que o tornou uma das soluções mais baratas e populares para projetos de Internet das Coisas (IoT).


O chip por si só é vendido em módulos pequenos (como o ESP-01, ESP-07, ESP-12E/F), mas a forma mais usada por estudantes e makers é através de uma placa de desenvolvimento chamada NodeMCU, que integra o módulo ESP8266 (geralmente o ESP-12E), um conversor USB-serial, regulador de tensão e pinos no padrão que facilita o uso em protoboard — de forma parecida com o Arduino Uno.

Pinagem da Placa NodeMCU


Na NodeMCU, os pinos são identificados por rótulos "D" impressos na placa (D0, D1, D2...), mas internamente cada um corresponde a um GPIO (General Purpose Input/Output) diferente do chip ESP8266. É importante conhecer essa correspondência ao programar, pois alguns pinos têm restrições de uso (por exemplo, D0 não suporta interrupções e alguns pinos são usados internamente durante o boot).

Por causa da tensão lógica de 3,3V, é preciso ter atenção ao ligar sensores projetados para 5V (como o HC-SR04 e o DHT11/DHT22) diretamente aos pinos do ESP8266 — em projetos mais rigorosos, recomenda-se o uso de divisores de tensão ou conversores de nível lógico para proteger as entradas do módulo.

Aplicações em IoT


Por unir baixo custo, tamanho reduzido e conectividade Wi-Fi nativa, o ESP8266 é amplamente usado em automação residencial (controle de lâmpadas e tomadas via internet), estações meteorológicas conectadas, sistemas de irrigação inteligente, monitoramento remoto de sensores via protocolos como MQTT e HTTP, e protótipos de produtos IoT antes de migrarem para soluções industriais mais robustas.

Circuito 1 — Sensor de Distância com Alerta

Componentes: NodeMCU ESP8266, sensor ultrassônico HC-SR04, LED.

O sensor ultrassônico mede continuamente a distância até um obstáculo. Sempre que um objeto é detectado a 20 cm ou menos, o LED acende como alerta de proximidade — a mesma lógica usada em sensores de ré e sistemas antichoque simples.

Código em C++

#define TRIG D4 #define ECHO D5 #define LED D2 void setup() { pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); pinMode(LED, OUTPUT); digitalWrite(LED, LOW); Serial.begin(115200); } void loop() { digitalWrite(TRIG, LOW); delayMicroseconds(2); digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW); long tempo = pulseIn(ECHO, HIGH); float distancia = tempo * 0.0343 / 2; Serial.print("Distancia: "); Serial.print(distancia); Serial.println(" cm"); if (distancia <= 20 && distancia > 0) { digitalWrite(LED, HIGH); } else { digitalWrite(LED, LOW); } delay(100); }

Circuito 2 — Sensor de Presença com Luminosidade

Componentes: NodeMCU ESP8266, sensor PIR, módulo LDR, LED.

O LED só acende quando as duas condições são verdadeiras ao mesmo tempo: presença detectada pelo PIR e ambiente considerado escuro pelo módulo LDR — a mesma lógica de iluminação automática usada em corredores e áreas comuns.

#define PIR D6 #define LDR D5 #define LED D2 void setup() { pinMode(PIR, INPUT); pinMode(LDR, INPUT); pinMode(LED, OUTPUT); digitalWrite(LED, LOW); Serial.begin(115200); } void loop() { int movimento = digitalRead(PIR); int luz = digitalRead(LDR); Serial.print("Movimento: "); Serial.print(movimento); Serial.print(" | LDR: "); Serial.println(luz); if (movimento == HIGH && luz == HIGH) { digitalWrite(LED, HIGH); } else { digitalWrite(LED, LOW); } delay(200); }

Circuito 3 — Monitor de Temperatura com Indicadores

Componentes: NodeMCU ESP8266, sensor de temperatura TMP36, 3 LEDs (verde, amarelo, vermelho).

A temperatura lida pelo TMP36 é convertida para graus Celsius e classificada em três faixas: abaixo de 25°C acende o LED verde (ideal), entre 25°C e 30°C acende o amarelo (atenção), e acima de 30°C acende o vermelho (alerta) — como um semáforo de temperatura.

#define LED_VERDE D1 #define LED_VERMELHO D2 #define LED_AMARELO D3 #define TMP36 A0 void setup() { pinMode(LED_VERDE, OUTPUT); pinMode(LED_VERMELHO, OUTPUT); pinMode(LED_AMARELO, OUTPUT); Serial.begin(115200); digitalWrite(LED_VERDE, LOW); digitalWrite(LED_AMARELO, LOW); digitalWrite(LED_VERMELHO, LOW); } void loop() { int valor = analogRead(TMP36); float tensao = valor * (3.3 / 1023.0); float temperatura = (tensao - 0.5) * 100.0; Serial.print("Temperatura: "); Serial.print(temperatura); Serial.println(" C"); digitalWrite(LED_VERDE, LOW); digitalWrite(LED_AMARELO, LOW); digitalWrite(LED_VERMELHO, LOW); if (temperatura < 25) { digitalWrite(LED_VERDE, HIGH); } else if (temperatura >= 25 && temperatura < 30) { digitalWrite(LED_AMARELO, HIGH); } else { digitalWrite(LED_VERMELHO, HIGH); } delay(500); }
